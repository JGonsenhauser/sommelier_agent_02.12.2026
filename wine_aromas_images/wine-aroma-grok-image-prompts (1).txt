WINE SENSORY AROMA TILES — GROK IMAGINE PROMPT PACK
=====================================================
A matching set of individual wine aroma / tasting-note images.
Every prompt uses the SAME locked layout so the tiles look like one collection.

HOW TO USE IN GROK IMAGINE
--------------------------
1. Set aspect ratio to Square / 1:1 BEFORE you generate.
2. Turn Quality mode on if it is available.
3. Generate GREEN APPLE first. That image is your visual anchor.
4. If Grok Imagine lets you attach a style/reference image, attach the green-apple result
   to every later generation. This is the single biggest consistency lock.
5. Paste ONE complete prompt per image. Do not shorten the locked language.
6. If an object looks wrong, regenerate that prompt. Do not rewrite lighting or background.
7. One aroma per image. The only mixed arrangements are the FAMILY cards.

LOCKED VISUAL SYSTEM (do not change between images)
----------------------------------------------------
- Square 1:1
- Photorealistic luxury food still-life
- One hero subject (or a tight named cluster) dead-centered, about 60% of the frame
- Dark walnut butcher-block with a faint slate inlay
- Warm key light from the upper left, soft rim light on the right
- Shallow depth of field, 85mm eye-level lens look
- Deep shadowy wine-cellar bokeh
- No text, no labels, no logos, no watermarks, no people, no hands, no wine bottles
- No objects except those named in the subject line
